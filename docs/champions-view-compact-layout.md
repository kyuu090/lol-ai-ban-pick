# Champions View Compact Layout

`ui/champions-view.ts` の詳細画面は、1画面内で主要な情報カテゴリを見渡せることを優先する。

## 方針

- 情報件数はなるべく削らず、カード内の余白・ラベル重複・グリッド配置を圧縮して収める。
- 上段はチャンピオン概要とキーストーン候補を横並びにし、キーストーン候補は `auto-fit` で1段に寄せる。
- 上段は `左: ルーン + サモナースペル / 右: 推奨アイテムビルド`、下段は `スキルオーダー` を横いっぱいに使う。
- スキルオーダー候補では `1位 スキルオーダー` のような行見出しを出さず、スキル列と `WR / Games` をカード直下に並べて外枠を一段減らす。
- 詳細カード見出し下の説明文は常時表示しない。キーストーン候補の直前にだけ、補助文として `キーストーンを選択してください` を置く。

## 実装メモ

- 単一アイテム系の行は、セクション見出しと同じ文言を行内で重複表示しない。
- ビルドカード内部は2カラムのサブグリッドにして、縦方向の伸びを抑える。
- ビルドカード内部は `開始 / ブーツ / 1st + 2nd` を上段、`3rd / 4th / 5th` を下段に置く 3 列グリッドで並べる。`6th` は表示しない。
- ビルド候補の行メタは `PR` を出さず、`WR / Games` のみを表示する。
- `PR / WR / Games` のチップは可読性を優先してやや大きめより少し上のサイズ感に保ち、ビルド候補内の派生チップも極端に小さくしない。
- ビルド候補の `WR / Games` チップは従来より文字をほんの少し大きくし、`WR` が 50% 未満のときは緑ではなく赤で表示する。
- ビルド候補のアイテムは ID 常時表示をやめ、アイコン中心で詰める。
- アイテムアイコンは一覧性を損なわない範囲でやや大きめに表示する。
- `firstSecondCoreItems` の 2 アイテムは同じボックス内で組み合わせのまま見せ、組み合わせ単位の `WR / Games` を表示する。ブロック間の矢印は表示しない。
- サモナースペルは独立カードにせず、ルーンカード下部の空き領域へ統合する。
- サモナースペルはテキストタグではなく、Data Dragon の spell icon と名前を併記して表示する。
- サモナースペル候補カード内では `N位 サモナースペル` の行を出さず、トークン列と `PR / WR / Games` だけを表示する。
- キーストーン候補は同じカード幅の中で、アイコンと名前を優先して大きめに見せる。
- ルーンカードは候補をタブで切り替え、常に1パターンだけ表示する。
- ルーン候補タブの表示名は `1位 / 2位` ではなく `Set1 / Set2` の形式にする。
- ルーンカード内で余白が余る場合は、ルーン木・シャード・サモナースペルのノードサイズと間隔を優先して広げ、カード幅を使い切る。
- ただしルーン木とシャードはカード内で収まることを優先し、はみ出す場合は先にそれらを少し縮める。サモナースペルはトークンサイズを維持しつつ、カード最小幅で収める。
- ルーンセット本文では `1位ルーンセット` と `ルーンシャード` の見出し行を出さず、`WR / Games` だけを右上へ寄せて上端を詰める。
- `シャード別傾向` の独立セクションは置かず、必要なシャード情報は選択中ルーンセット内に含める。
- ルーンセットごとの `WR / Games` はタブ本文ヘッダーで表示し、シャードはサブルーンの右横に置く。
- ルーンシャードの画像は Data Dragon の `perk-images/StatMods/*.png` を使うが、公開 JSON には ID 対応がないため `SHARD_ICON_PATHS` に手動対応を閉じ込める。
- ルーンシャードはゲーム内に近い 3 行配置で全候補を表示し、選択中だけ明るく、未選択はグレーアウトする。
- 選択中シャードの背景色はルーンツリーと同系の暗色を維持し、視認性は枠線と発光で出す。
- Stats API 詳細ビュー固有の配色は `styles/stats.css` 側で `--stats-api-*` トークンに寄せ、ダークモード時の値は `styles/theme.css` で上書きする。
- シャードの選択判定は ID 集合ではなく API 配列の行順を使い、同じ shard ID が複数行に現れても各行で 1 つだけ点灯させる。
- `statShards` は rune set と単純な同順位対応ではないケースがあるため、表示時は配列全体から各行の選択を復元する。
- 少なくとも `shardIds: [5008, 5010, 5001]` の再現ケースを自動テストで検知できるようにしている。
- 一覧上部の件数・パッチ・レーン・更新日メタ表示と、詳細内の `Data watermark` は表示しない。状態表示欄はローディングやエラー時の案内にだけ使う。
- `styles/responsive.css` では `1000px` 以下で各サブグリッドを1カラムへ戻す。
